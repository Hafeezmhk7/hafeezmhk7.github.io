# hafeezmhk7.github.io

Personal academic website of Mohammad Hafeez Khan. It is a single static page (`index.html`) with a layout inspired by [Jon Barron's website](https://github.com/jonbarron/website), served by GitHub Pages.

- `images/`: profile photo and publication thumbnails
- `files/`: CV, theses and reports (PDF)

To add a publication, copy one of the `<div class="entry">` blocks in `index.html`.
